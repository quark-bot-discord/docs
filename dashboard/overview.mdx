The dashboard is at [quark.bot/dashboard](https://quark.bot/dashboard). Sign in with Discord. If you have Manage Channels and Manage Server, you can also run `/dashboard` in your server to get a link straight to it.

## Who can open a server's dashboard

- Anyone with **Administrator**, **Manage Server**, **Manage Channels** or **Manage Webhooks** in the server. They get full access.
- Anyone who has been [given access](/dashboard/access) by one of those people. They see only what they were given.

## Choosing a server

The first page lists your servers under two tabs, **With Quark** and **All servers**. If someone has shared a server with you, it appears in a **Shared with you** section above your own.

## Pages

Each server has these pages in the sidebar:

| Page | What it is for |
| --- | --- |
| Logging | Log channels, ignore rules, and settings for each log type. See [where logs go](/logs/overview#where-logs-go) and [options](/logs/options) |
| Log Viewer | Your logs on the web. See [log viewer](/logs/viewer) |
| Automations | Rules that do something extra when a log is produced. See [automations](/dashboard/automations) |
| Tags | Create and edit tags. See [tags](/commands/tags) |
| Settings | Language, status updates, dashboard access, API tokens, importing settings and reset |

### Logging

The Logging page has four tabs:

| Tab | What you set there |
| --- | --- |
| Channels | The main log channel, a channel or on/off switch for each category, and the two special categories, Files and Age-restricted |
| Ignore Rules | People, roles, channels, categories and message content to leave out, and whether actions by bots are logged |
| Other | Spoilers, which buttons appear on logs, log format, how long modlog reasons stay editable, PluralKit compatibility and Pro upsell logs |
| Individual Log Config | Settings for one log type at a time: on or off, format, channel and colour |

### Settings

| Setting | What it does |
| --- | --- |
| Language | The language of every message Quark sends in your server. See [languages](/languages/overview) |
| Status updates | The channel where announcements from the Quark developers about releases and downtime are posted, or Off |
| Dashboard Access | Give a role or a person part of the dashboard. See [sharing access](/dashboard/access) |
| API Access Tokens | Create and revoke tokens for the [API](/api-reference/introduction). Up to five per server |
| Import settings | Copy another server's settings into this one. See [below](#import-settings-from-another-server) |
| Reset | Deletes Quark's configuration for the server. This cannot be undone |

Dashboard Access, API Access Tokens, Import settings and Reset are only shown to people who manage the server in Discord, never to people who were given access.

Status updates are a channel follow in Discord, so Quark needs the **Manage Webhooks** permission to show or change where they go.

<Warning>**Reset** removes your log channels, ignore rules, per-log settings, automation rules, tags, API tokens and access grants, and the history of changes to modlog reasons. It does not delete logs already posted in your Discord channels. Revoke your API tokens before you reset: the reset removes their records, so they can no longer be listed or revoked afterwards.</Warning>

### Import settings from another server

If you run more than one server, you can set one up and copy its settings to the others.

<Steps>
  <Step title="Choose the server to copy from">
    Under **Settings**, press **Import from another server**. The list shows the other servers you manage in Discord where Quark is set up.
  </Step>
  <Step title="Choose what to copy, and the channels and roles">
    Tick the parts you want: logging options and log types, where logs go, ignore rules, tags, automations, dashboard access and language.

    Channels and roles are not shared between servers. For each one the other server uses, choose the channel or role in this server to use in its place, or leave it out. One with the same name here is chosen for you to start with. Every change is listed before anything is changed.
  </Step>
  <Step title="Import">
    Keep the page open until it finishes. Anything that could not be changed is listed with the reason.
  </Step>
</Steps>

What an import does and does not do:

- A channel this server already uses is only replaced by a channel you choose. It is never cleared or switched off.
- Ignore rules, tags, automations and dashboard access are added to what is already here. Nothing is removed, and access somebody already has here is not changed.
- Anything that uses a channel or role you left out is not copied. An automation is copied whole or not at all.
- An automation arrives as it is in the other server: on, off or as a dry run. If a rule that holds logs back cannot be copied, the rules after it arrive switched off.
- Formats, colours, bot rules and a log type's own channel need Quark Pro or Pro Lite on the server you import into. Automations that need Quark Pro need it there too.
- API tokens, the status updates channel and unused dashboard invite links are never copied.
- The other server is not changed.
- Each change is logged as a change made by hand would be. There is no undo.

## Quark and Quark Pro tabs

At the top of each server's dashboard are two tabs, **Quark** and **Quark Pro**. They are two separate bots, and each has its own configuration. Settings you change on one tab do not affect the other. See [subscriptions](/subscriptions/overview) for what the Pro bot is.

## Staying on top of problems

- The **stethoscope** button opens the [troubleshooter](/troubleshooting). It shows a red badge when something is stopping logs and an amber one when some logs are affected.
- The **bell** lists recent changes to Quark's settings in the server and who made them.
- A **Finish setting up** card on the Logging page lists what is left to do: choose where logs go, receive your first log, and, if you have a subscription, apply it and add the Pro bot. You can dismiss it.
- The Channels tab warns you when a log channel has no webhook (press **Fix**) or is over Discord's rate limit.

## If you remove and re-add Quark

When Quark is removed from a server, its configuration for that server is kept for a limited time. If you add Quark again before it expires, the dashboard asks whether to **Load Old Configuration** or **Start Fresh**.
