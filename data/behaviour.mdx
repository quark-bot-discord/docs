Message text, files and log history are kept for a limited time. This page lists the limits.

## How long data is kept

| Data | Without Quark Pro | With Quark Pro |
| --- | --- | --- |
| Message text | 12 hours | 30 days |
| Copies of attached files | Up to 1 day | Up to 30 days |
| Log history on quark.bot | Up to 1 day. The log viewer shows the last hour | 30 days |
| Avatars, icons and similar images | Up to 180 days | Up to 180 days |
| Backups of log history | 14 days | 14 days |
| Server configuration | Until the configuration is reset. After Quark is removed, it is kept for a limited time so it can be restored | Same |

Pro Lite has the same limits as the free plan.

Details about your server's members, roles and channels are kept while Quark is in the server.

### Messages

Quark stores a message when it is sent and keeps it for 12 hours after it was sent or last edited, or 30 days on Quark Pro. After that, Quark cannot show what the message said. See [message age](/logs/behaviour#message-age).

The limit is set when the message is stored. Upgrading to Quark Pro extends it for messages sent from then on, not for messages already stored.

### Files

Quark keeps a copy of each attached file so that it can re-post it if the message is deleted. The copy is removed as soon as the log containing it has been delivered, and otherwise when its time limit runs out.

### Log history

Each log is also recorded so the [log viewer](/logs/viewer) can show it. That record holds text and file names. It does not hold the files themselves.

### Logs in your Discord channels

A log that has been posted to your log channel is a message in your server. Quark's time limits do not apply to it. It stays until someone in your server deletes it.

## What you can control

| To do this | Do this |
| --- | --- |
| Stop logging a channel | Add the channel to the [ignore options](/logs/options#ignore-options). Messages and files there are still stored for their usual time |
| Stop Quark receiving a channel at all | Remove Quark's View Channel permission in that channel |
| Stop logging a member or role | Add them to the ignore options |
| Stop a kind of log | Switch off the log type or its category |
| Decide who can read logs on the web | Manage [dashboard access](/dashboard/access) |
| Delete Quark's configuration for your server | **Settings → Reset** on the dashboard |

**Reset** deletes your server's configuration: log channels, ignore options, per-log settings, tags, API token records and access grants. Revoke your API tokens before you reset. It does not delete stored messages, files or log history, which expire on their own within the limits above, and it does not delete logs already posted in your Discord channels.

## If you remove Quark

Quark stops receiving anything from your server. Its configuration for the server is kept for a limited time, so that if you add Quark again soon you can choose to restore it. Stored files and log history are not deleted at that moment. They expire within the limits above.

## Asking for your data to be deleted

If you are a member of a server that uses Quark and want to know what Quark holds about you, or want it deleted, follow the contact details in the [privacy policy](https://quark.bot/legal/privacy-policy). Logs already posted in a server's log channel are held by Discord and controlled by that server's staff.
