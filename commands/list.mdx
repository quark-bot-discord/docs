All commands are slash commands, apart from three that are in the menu you get by right-clicking (or long-pressing) a message and choosing **Apps**: **See initial reactors**, **Get IDs** and **Report log issue**. Commands only work inside a server, not in DMs.

Replies are only visible to you, with two exceptions: the tag posted by `/tags send`, and `/troubleshoot` when you set `share` to true.

"Who can use it by default" is the Discord permission a member needs before the command shows up for them. Where two permissions are listed, the member needs both. Administrators can use everything. You can change who sees each command in **Server Settings → Integrations → Quark**.

<Note>If your Discord app is not set to English, some command names are translated. `/ban` is `/verbannen` in Dutch, for example.</Note>

See [how commands behave](/commands/behaviour) for the rules each moderation command follows and what the message menu commands do, and [tags](/commands/tags) for `/tags`.
