## What you can change

| What | Where on the dashboard | Plan |
| --- | --- | --- |
| A channel for each category | Logging → Channels | Free |
| Switch a category or a log type off | Logging → Channels, Logging → Individual Log Config | Free |
| Which standard buttons appear on logs | Logging → Other → Buttons | Free |
| Spoiler re-posted files | Logging → Other → Spoilers | Free |
| Language | Settings → Language | Free |
| Colour of a log type | Logging → Individual Log Config → Embed Color | Pro Lite or Pro |
| One of Quark's own formats, for all logs | Log Formats | Free |
| Which parts a log shows, its wording, buttons and layout, for every log or one log type | Log Formats → Create a format | Pro Lite or Pro |
| Logs drawn as pictures | Log Formats → Image cards, or the Image layout | Pro |
| A channel for one log type | Logging → Individual Log Config → Separate Logging Channel | Pro Lite or Pro |
| Log actions by and to bots | Logging → Ignore Rules → Actions by bots, Actions on bots | Pro Lite or Pro |
| The name and avatar logs are posted under | Logging → Other → Log name and avatar | Pro Lite or Pro |

Quark's own formats are free on every plan, and so is building your own. Posting logs in a format you made needs Pro Lite or Pro.

## Colours

Each log type has a default colour. To change one, go to **Logging → Individual Log Config**, choose the log type, and pick an **Embed Color**. You can reset it to the default at any time.

Colours are set per log type. There is no single colour for all logs.

## Formats

| Format | What it looks like |
| --- | --- |
| Standard | An embed. This is the default |
| Standard (no embed) | The same information as plain text instead of an embed |
| Compact | A small embed with one or two lines for each log |
| Compact (no embed) | One or two lines of plain text, and no buttons |
| Basic, Basic (no embed) | Each log's facts and nothing else, with no icons |
| Detailed | Standard with every extra detail a log has |
| JSON | Each log as JSON, for another bot to read |
| Components | Laid out with Discord's newer components, with the buttons inside the message |
| Image cards | Each log drawn as a picture. Quark Pro only |

Set the format on the **Log Formats** page. Individual Log Config no longer has a Format option: to make one log type look different, build a format and change that log in it.

On the same page you can build a format of your own: hide or spoiler parts of a log, add extra information, your own text and link buttons, and change the colour or layout, one log at a time. A format can be shared with a link. See [log formats](/dashboard/formats).

## A channel for one log type

By default a log goes to its category's channel. With Pro Lite or Pro you can send a single log type somewhere else, for example bans to a channel of their own while other modlogs stay together.

Go to **Logging → Individual Log Config**, choose the log type, and set **Separate Logging Channel**. You can also do this in Discord: run `/logging`, pick the category, then the log type.

## Name and avatar

Logs are posted under **Quark**, **Quark Pro Lite** or **Quark Pro**. With Pro Lite or Pro you can post them under a name of your own, with Quark's avatar or your server's icon.

Go to **Logging → Other → Log name and avatar**, type a name, choose the avatar and press **Save**. The preview shows how logs will look. Leave the name empty to keep Quark's.

This applies to every log channel, including ones you set later. New logs use it straight away; logs already posted keep the name they were posted under. If you chose your server's icon, logs follow it when the icon changes.

A name can be up to 80 characters. Discord doesn't allow "discord" or "clyde" in it, "everyone" or "here" as the whole name, or the characters @, #, : and ```.

Renaming Quark's webhook in Discord does not change the name: Quark sets the name on every log.

## Try the paid options for free

Locked options on the dashboard link to Quark's vote page. Each vote on Top.gg unlocks Pro Lite on your server for 24 hours. See [voting](/subscriptions/voting).

## When a plan ends

Your colours, your own formats and per-log channels stay saved, but Quark stops applying them and goes back to the defaults. Logs go back to Quark's name and avatar; your choice is kept for when the plan is back. A format you built is kept as it was, and its changes are parked. They apply again as soon as the server has Pro Lite or Pro.
