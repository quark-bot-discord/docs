## What you can change

| What | Where on the dashboard | Plan |
| --- | --- | --- |
| A channel for each category | Logging → Channels | Free |
| Switch a category or a log type off | Logging → Channels, Logging → Individual Log Config | Free |
| Which standard buttons appear on logs | Logging → Other → Buttons | Free |
| Spoiler re-posted files | Logging → Other → Spoilers | Free |
| Language | Settings → Language | Free |
| Colour of a log type | Logging → Individual Log Config → Embed Color | Pro Lite or Pro |
| One of Quark's own formats, for all logs | Log Formats | Free |
| Which parts a log shows, its wording, buttons and layout, for every log or one log type | Log Formats → Create a format | Pro Lite or Pro |
| Logs drawn as pictures | Log Formats → Image cards, or the Image layout | Pro |
| A channel for one log type | Logging → Individual Log Config → Separate Logging Channel | Pro Lite or Pro |
| Log actions by and to bots | Logging → Ignore Rules → Actions by bots, Actions on bots | Pro Lite or Pro |
| The name and avatar logs are posted under, for the server or one log channel | Logging → Other → Log name and avatar | Pro Lite or Pro |

Quark's own formats are free on every plan, and so is building your own. Posting logs in a format you made needs Pro Lite or Pro.

## Colours

Each log type has a default colour. To change one, go to **Logging → Individual Log Config**, choose the log type, and pick an **Embed Color**. You can reset it to the default at any time.

Colours are set per log type. There is no single colour for all logs.

## Formats

| Format | What it looks like |
| --- | --- |
| Standard | An embed. This is the default |
| Standard (no embed) | The same information as plain text instead of an embed |
| Compact | A small embed with one or two lines for each log |
| Compact (no embed) | One or two lines of plain text, and no buttons |
| Basic, Basic (no embed) | Each log's facts and nothing else, with no icons |
| Detailed | Standard with every extra detail a log has |
| JSON | Each log as JSON, for another bot to read |
| Components | Laid out with Discord's newer components, with the buttons inside the message |
| Image cards | Each log drawn as a picture. Quark Pro only |

Set the format on the **Log Formats** page. Individual Log Config no longer has a Format option: to make one log type look different, build a format and change that log in it.

On the same page you can build a format of your own: hide or spoiler parts of a log, add extra information, your own text and link buttons, and change the colour or layout, one log at a time. A format can be shared with a link. See [log formats](/dashboard/formats).

## A channel for one log type

By default a log goes to its category's channel. With Pro Lite or Pro you can send a single log type somewhere else, for example bans to a channel of their own while other modlogs stay together.

Go to **Logging → Individual Log Config**, choose the log type, and set **Separate Logging Channel**. You can also do this in Discord: run `/logging`, pick the category, then the log type.

## Name and avatar

Logs are posted under **Quark**, **Quark Pro Lite** or **Quark Pro**, with Quark's picture. With Pro Lite or Pro you can post them under a name and picture of your own, for the whole server and for each log channel.

Go to **Logging → Other** and scroll to **Log name and avatar** at the bottom. Type a name, and choose an avatar. Changes save as you make them: an avatar straight away, a name when you stop typing or leave the field. The preview shows how logs will look. Leave the name empty to keep Quark's.

| Avatar | What it is |
| --- | --- |
| Quark's | Quark's picture for your plan |
| Server icon | Your server's icon, as it is when each log is sent. It can't be chosen while the server has no icon |
| Quark's pictures | Quark's logo in six colours, and a shield, gavel, eye, bell, scroll, message, members and voice symbol. Under **More pictures** |
| Server emojis | Any of your server's custom emojis. Under **More pictures** |
| Role icons | The icon of any role that has one. Under **More pictures**. Role icons need server boost level 2 |

You can't upload a picture. If the emoji or role icon you chose is deleted, or your server removes its icon, logs go back to Quark's picture. No log is lost over it.

A name can be up to 80 characters. Discord doesn't allow "discord" or "clyde" in it, "everyone" or "here" as the whole name, or @, #, :, ``` and invisible characters. The field says so as you type, and a name Discord would refuse is not saved.

### A different one for a log channel

Under **Per log channel**, each of your log channels is listed with what is sent there: the main channel, each category's channel, Files, Age-restricted, and the channels of log types that have one of their own. A channel used for several of these is listed once. Give any of them a name or avatar of its own, for example "Mod Log" with the gavel in your modlog channel. Leave the name empty, or the avatar on **Same as server**, and that channel uses the setting above.

- A new name or avatar is used from the next log. Logs already posted keep the name they were posted under.
- If you move a category to a different channel, its logs take that channel's own setting, or the server's if it has none.
- Renaming Quark's webhook in Discord does not change the name. Quark sets the name and avatar on every log.
- A log Quark posts itself, because the channel has no webhook, appears under the bot's own name and picture. See [how logs are delivered](/logs/behaviour#how-logs-are-delivered).
- Each change produces a **Logging Options Updated** log in Quark Events.
- [Import settings](/dashboard/overview#import-settings-from-another-server) copies the name and avatar to a server with Pro Lite or Pro, and each log channel's own to the channel you pair with it. A role icon is matched to the role you pair it with. An emoji belongs to the other server, so this server keeps its own avatar instead, and the import says so.

## Try the paid options for free

Locked options on the dashboard link to Quark's vote page. Each vote on Top.gg unlocks Pro Lite on your server for 24 hours. See [voting](/subscriptions/voting).

## When a plan ends

Your colours, your own formats, per-log channels and log name and avatar stay saved, but Quark stops applying them and goes back to the defaults. A format you built is kept as it was, and its changes are parked. They apply again as soon as the server has Pro Lite or Pro.
