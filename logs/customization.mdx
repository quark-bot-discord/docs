## What you can change

| What | Where on the dashboard | Plan |
| --- | --- | --- |
| A channel for each category | Logging → Channels | Free |
| Switch a category or a log type off | Logging → Channels, Logging → Individual Log Config | Free |
| Which standard buttons appear on logs | Logging → Other → Buttons | Free |
| Spoiler re-posted files | Logging → Other → Spoilers | Free |
| Language | Settings → Language | Free |
| Colour of a log type | Logging → Individual Log Config → Embed Color | Pro Lite or Pro |
| Format, for all logs or one type | Log Formats, Logging → Individual Log Config → Format | Pro Lite or Pro |
| Which parts a log shows, its wording, buttons and layout | Log Formats → Create a format | Pro Lite or Pro |
| A channel for one log type | Logging → Individual Log Config → Separate Logging Channel | Pro Lite or Pro |
| Log actions by and to bots | Logging → Ignore Rules → Actions by bots, Actions on bots | Pro Lite or Pro |

Building a format is free on every plan. Posting logs in it needs Pro Lite or Pro.

## Colours

Each log type has a default colour. To change one, go to **Logging → Individual Log Config**, choose the log type, and pick an **Embed Color**. You can reset it to the default at any time.

Colours are set per log type. There is no single colour for all logs.

## Formats

| Format | What it looks like |
| --- | --- |
| Standard | An embed. This is the default |
| Standard (no embed) | The same information as plain text instead of an embed |
| Compact | A small embed with one or two lines for each log |
| Compact (no embed) | One or two lines of plain text, and no buttons |

Set the format for every log on the **Log Formats** page, or override it for one log type under **Logging → Individual Log Config → Format**.

On the same page you can build a format of your own: hide or spoiler parts of a log, add extra information, your own text and link buttons, and change the colour or layout, one log at a time. A format can be shared with a link. See [log formats](/dashboard/formats).

## A channel for one log type

By default a log goes to its category's channel. With Pro Lite or Pro you can send a single log type somewhere else, for example bans to a channel of their own while other modlogs stay together.

Go to **Logging → Individual Log Config**, choose the log type, and set **Separate Logging Channel**. You can also do this in Discord: run `/logging`, pick the category, then the log type.

## Try the paid options for free

Locked options on the dashboard link to Quark's vote page. Each vote on Top.gg unlocks Pro Lite on your server for 24 hours. See [voting](/subscriptions/voting).

## When a plan ends

Your colours, formats and per-log channels stay saved, but Quark stops applying them and goes back to the defaults. A format you built is kept as it was, and its changes are parked. They apply again as soon as the server has Pro Lite or Pro.
