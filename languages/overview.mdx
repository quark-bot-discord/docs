Quark's logs and command replies can be shown in 19 languages. The language is a setting for the whole server.

## Change your server's language

- In Discord: run `/language` and choose from the list. You need **Manage Channels** and **Manage Server**.
- On the dashboard: **Settings → Language**.

When Quark joins a Community server, it starts in the server's primary language where it can. Otherwise it starts in English (US). You can change it at any time.

Changing the language produces a **Language Changed** log.
