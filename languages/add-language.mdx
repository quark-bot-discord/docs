---
title: Adding a new language
description: 'Add a language Quark does not have yet'
---

If your language is not in the [supported list](/languages/overview#supported-languages), you can start it yourself. You need a Weblate account first. See [start translating](/languages/start-translating).

<Steps titleSize="h3">
    <Step title="Find the language code">
        Look up the code for your language in this [list of language codes](https://www.w3schools.com/tags/ref_language_codes.asp). French is `fr`, for example.
    </Step>
    <Step title="Open the language on Weblate">
        Put the code at the end of this address:
        ```
        https://languages.quark.bot/projects/quark-bot/-/LANGUAGE_CODE/
        ```
        For French:
        ```
        https://languages.quark.bot/projects/quark-bot/-/fr/
        ```
    </Step>
    <Step title="Start the first component">
        Press the **+** button next to the first component. You only need to do this once.
        <Warning>It can take a moment for the change to appear.</Warning>
        ![Create translation](/images/add-language/createTranslation.png)
    </Step>
    <Step title="Translate">
        Translate the strings, following the [rules for translations](/languages/start-translating#rules-for-translations).
    </Step>
</Steps>

A new language has to be switched on by the developers before it can be chosen in `/language`. Ask in the [support server](https://quark.bot/support) when your translation is ready.
